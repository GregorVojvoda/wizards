This is a simple application acting as a scorekeeper for the card game Wizard. 
Is a spring boot application with a simple HTML and JavaScript frontend.

You can run the application locally by running the command 
```bash
./mvnw spring-boot:run
```

The application will be available at http://localhost:8080

To initialize a game and track predictions and scores you can find an http file with a simple example in src/test/resources/assets/client.http.
